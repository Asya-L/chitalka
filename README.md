# Между строк

Изучение языков по своим книгам — английский, польский, китайский.

- **Полка.** Книги EPUB, FB2 (в т.ч. `.fb2.zip`), TXT и PDF с текстовым слоем (абзацы собираются заново, колонтитулы и номера страниц убираются, главы — по оглавлению PDF). Язык определяется сам, главы — по оглавлению или заголовкам.
- **Читалка.** Нажатие на слово — перевод именно в этом предложении, начальная форма, пояснение формы (падеж, вид, время, счётное слово) с учётом уровня. Выделение — перевод фразы. Перевод всего предложения, озвучка, пиньинь над китайским текстом. Сохранённые слова подсвечиваются во всех книгах.
- **Слова.** Интервальное повторение: на карточке — слово и предложение из книги, где оно встретилось. Лимит новых слов в день.
- **Дневник.** Минуты в день против цели, серия дней, прочитанные слова, статистика по языкам и книгам.
- **Без ключей.** Частотность слова и уровень HSK, понятность книги по уровню с первого дня, офлайн-словарь китайского CC-CEDICT, «где ещё в книге», перевод абзаца (долгое нажатие), цитаты и закладки, курсив и иллюстрации из EPUB/FB2, поиск по книге, разворот в две колонки на компьютере, карточки «выбор», «собери предложение», «диктант», повторение за диктором, мини-повторение перед главой, порядок черт иероглифов, тоны на слух, таблицы склонения и спряжения польских слов из Викисловаря, цели, прогноз окончания книги, календарь года.
- **Сначала вход.** При запуске — экран входа (вход, регистрация, восстановление пароля); приложение открывается только после авторизации.
- **Упражнения.** Раздел «Практика»: пары, пропуски в абзаце, найди в тексте, на слух, спринт, собери предложение, диктант; польские падежи и предлоги; английские неправильные глаголы; китайские пиньинь ↔ иероглиф, собери слово, счётные слова, тоны, порядок черт; «Тренировка дня». Всё на своих словах и книгах; ошибки отправляют слово в повторение.
- **Синхронизация.** Слова, прогресс и тексты книг одинаковые на телефоне и компьютере (Supabase). Изменения с разных устройств сливаются по записям, а не затирают друг друга.

Перевод — Google Переводчик / MyMemory, словари и Викисловарь, без ключей. Функции на Claude (перевод в контексте, вопросы по главе, разговор о книге, грамматика) пока выключены: код остался, включается только флагом разработки `localStorage['mezhdu-ai']='1'`.

## Устройство

Статическое PWA без сборки: устанавливается на телефон, работает офлайн (кроме перевода).

- `index.html`, `app.css`, `app.js` — приложение; `learn.js` — обучение поверх чтения; `extras.js` — то, что работает без ключей; `exercises.js` — раздел упражнений (частотность, словарь, цитаты, разворот, новые карточки, тоны, порядок черт, цели)
- `data/` — частотные списки, HSK и словарь CC-CEDICT (см. «Данные и лицензии»)
- `parse.js` — разбор EPUB / FB2 / TXT / PDF (pdf.js подгружается с jsDelivr при первом PDF)
- `config.js` — адрес проекта Supabase и публичный ключ
- `schema.sql` — таблица `mezhdu_state` и закрытая корзина `books` с правилами доступа (уже выполнено в проекте)
- `sw.js`, `manifest.webmanifest`, `icon*` — установка и офлайн
- `android/` — приложение для Onyx Boox и других Android (WebView). APK собирается GitHub Actions и выкладывается в релиз «apk»: https://github.com/Asya-L/chitalka/releases/latest/download/mezhdu-strok.apk
- `tests/e2e.py` — сквозные тесты (Playwright, моки Claude и Supabase)

## Данные и лицензии

- `data/freq-en.txt`, `data/freq-pl.txt` — первые 30 000 слов из списков [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (Hermit Dave, по субтитрам OpenSubtitles 2018), CC BY-SA 4.0.
- `data/hsk.tsv` — слова HSK 3.0 (уровни 1–6 и 7–9) из пакета [hsk3.1-syllabus](https://www.npmjs.com/package/hsk3.1-syllabus), MIT.
- `data/cedict.tsv` — [CC-CEDICT](https://cc-cedict.org/) (MDBG), CC BY-SA 4.0; формат упрощён: `слово<TAB>пиньинь|значения`.
- Порядок черт — [Hanzi Writer](https://hanziwriter.org/) (MIT) и данные hanzi-writer-data (Arphic Public License), загружаются с jsDelivr при первом использовании.
- Чтение PDF — [pdf.js](https://mozilla.github.io/pdf.js/) (Apache 2.0).
- Таблицы форм польских слов — английский Викисловарь (CC BY-SA), запрашиваются по нажатию и кэшируются на устройстве.
