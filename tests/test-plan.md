# Тест-план «Между строк»

Нумерация: `F<раздел>-H<n>` — основной путь, `-E<n>` — пограничный случай, `-N<n>` — негативный.
Колонка «Как»: `авто` — `tests/e2e.py` (Playwright; Claude, переводчики и Supabase подменены) или `tests/push_test.mjs`;
`живой` — проверка на опубликованном сайте и настоящем Supabase; `CI` — сборка в GitHub Actions; `ручной` — нужен человек и устройство.
Во всех автотестах дополнительно проверяется: нет ошибок в консоли и нет горизонтальной прокрутки.
